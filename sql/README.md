# Запуск исходной загрузки

Требования: PostgreSQL, клиент psql, семь CSV из data/README.md в каталоге data/raw. База должна использовать UTF8. Скрипты запускаются из корня репозитория.

## Проверка в отдельной базе

Основная база olist_delivery уже заполнена вручную. Для проверки скрипта создайте через pgAdmin отдельную пустую базу olist_delivery_test. Не удаляйте таблицы или данные основной базы.

Откройте PowerShell в папке проекта. На текущем компьютере psql найден по пути C:\Program Files\PostgreSQL\18\bin\psql.exe. На другом компьютере замените путь, пользователя, хост и порт при необходимости.

Создание таблиц:

```powershell
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -X -h 127.0.0.1 -p 5432 -U postgres -d olist_delivery_test -W -v ON_ERROR_STOP=1 -f sql/01_create_raw.sql
```

Только после успешного создания таблиц выполните импорт:

```powershell
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -X -h 127.0.0.1 -p 5432 -U postgres -d olist_delivery_test -W -f sql/02_load_data.sql
```

Пароль вводится в приглашении psql и не сохраняется в файлах проекта. Параметр -X отключает пользовательские настройки psql для более предсказуемого запуска.

02_load_data.sql использует команду клиента psql \copy и не предназначен для Query Tool. Пути к CSV относительные: текущей папкой должен быть корень проекта. HEADER true пропускает первую строку файла; стандартные Quote и Escape для CSV — двойная кавычка.

Все семь загрузок заключены в одну транзакцию BEGIN/COMMIT. При ошибке выполнение останавливается; при завершении сеанса незавершённая транзакция откатывается. Скрипт блокирует параллельное изменение таблиц на время импорта. Если хотя бы одна таблица заполнена, импорт завершается ошибкой до загрузки. Скрипт не очищает таблицы и не исправляет структуру уже существующих таблиц.
