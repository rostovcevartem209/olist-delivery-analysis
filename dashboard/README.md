# Отчёт Power BI

Файл отчёта — olist_delivery_analysis.pbix. Данные импортируются из PostgreSQL, база olist_delivery на 127.0.0.1:5432. Представление mart.order_delivery импортировано под именем mart order_delivery.

Меры для последовательного создания приведены в measures.dax. Вычисляемые столбцы и календарь приведены в model.dax. Активная связь Календарь[Date] → mart order_delivery[Дата покупки] имеет кратность 1 ко многим, фильтр идёт от календаря к заказам.

График по месяцу покупки использует Календарь[Месяц] и меру Доля просрочек. Фильтр Период сравнения = TRUE установлен на уровне графика. Март 2018 сверён по подсказке с SQL, 7003 пригодных заказа, 1328 просрочек, 18.96%.

Сборка страниц отчёта продолжается. Снимки готовых страниц и итоговая сверка ещё предстоят.

Распределение по delay_group сверено по подписям диаграммы. Для групп «Вовремя или раньше», «1–3 дня», «4–7 дней», «8–14 дней», «15 дней и более» получены 89936, 1870, 1802, 1478 и 1384 заказа соответственно.

На странице «Обзор доставки» создан срез customer_state. При выборе SP карточки показали 40494 пригодных заказа, 1820 просрочек и 4.49%, что совпало с SQL. На скриншоте также видны пересчитанные графики и сроки доставки. Фильтр периода сравнения относится к месячному графику. Карточки и распределение задержек используют весь период в рамках выбранного штата.

После снятия выбора SP общие показатели восстановились. Названия графиков указывают период расчёта. Файл PBIX сохранён с первой страницей для промежуточной фиксации проекта. Оформление и остальные страницы ещё разрабатываются.

## Страница «Задержки и отзывы»

Создана таблица по delay_group с числом пригодных заказов и отзывов, покрытием и средней оценкой. Все пять групп сверены с SQL. Числа пригодных отзывов составили 89263, 1436, 396, 57 и 19. Покрытие составляет 99.25%, 76.79%, 21.98%, 3.86% и 1.37%. Средние оценки составили 4.29, 3.75, 3.69, 3.53 и 2.89. Общий итог таблицы содержит 96470 заказов, 91171 отзыв и покрытие 94.51%.

Меры числа и доли оценок 1–2 добавлены в таблицу и сверены по всем пяти группам. Получены числа 8258, 267, 81, 15, 8 и доли 9.25%, 18.59%, 20.45%, 26.32%, 42.11%. Общий итог составляет 8629 низких оценок, 9.46%. Для группы от 15 дней подтверждена отметка Менее 30 отзывов.

Создана гистограмма с двумя рядами на общей процентной шкале, доля низких оценок и покрытие отзывами. В подсказках добавлены количество и объём отзывов. Порядок групп по длительности задержки подтверждён по скриншоту. Для таблицы и графика задан отбор Пригодные заказы > 0, пустая группа исчезла.

Созданы столбец Группа доставки и таблица сравнения. По скриншоту сверены своевременные заказы с 89263 пригодными отзывами, покрытием 99.25%, средней оценкой 4.29 и долей низких оценок 9.25%. Для просроченных заказов сверены 1908 отзывов, покрытие 29.20%, средняя оценка 3.72 и доля низких оценок 19.44%.

Создан график распределения оценок 1–5 с отдельными рядами по группе доставки. Столбцы показывают долю оценки внутри соответствующей группы. Контрольные значения записаны в reports/reviews_analysis.md. По двум подсказкам оценки 5 сверены своевременная доставка 62.28% и 55593 отзыва, доставка с опозданием 40.57% и 774 отзыва.

На страницу добавлен срез штата покупателя. По скриншоту для SP подтверждены отзывы 38427/701, покрытие 99.36%/38.52% и доли низких оценок 8.66%/17.97% для своевременных/просроченных соответственно.

При проверке выбора оценки 5 на диаграмме выявлено, что мера Низкие оценки заменяла фильтр review_score и показывала 8258 оценок 1–2 при выбранных пятёрках. В measures.dax добавлен KEEPFILTERS, сохраняющий пересечение с выбранной оценкой. Исправление перенесено в Power BI: повторный скриншот подтвердил 55593 пригодных отзыва, среднюю оценку 5.00, ноль оценок 1–2 и долю 0.00% при выборе пятёрки своевременной доставки.

Матрица по категориям и группам доставки создана с мерой Пригодные отзывы категории. Видимые значения baby 2474/58 и auto 3479/83 совпали с SQL. Общий итог матрицы на скриншоте составляет 87282 своевременных и 1878 просроченных заказов с пригодным отзывом на подвыборке одной известной категории.
