# Анализ этапов доставки Olist

База анализа — 96 470 пригодных заказов доставки, определённых is_delivery_eligible в staging.order_quality. Для этапов не нужны соединения с отзывами и товарными позициями.

Проверяются интервалы purchased_at → approved_at, approved_at → carrier_at, carrier_at → delivered_at. Для каждого интервала отдельно обе метки должны быть заполнены и конечны, конец не раньше начала. Приоритет причины исключения: отсутствующие даты, бесконечные даты, обратный порядок. Проблема другого интервала сама по себе не исключает пригодный интервал этого же заказа. Общая проверка полного порядка этапов остаётся отдельным флагом качества.

Пользователь подтвердил покрытие трёх интервалов:

| Этап | Всего заказов | Нет дат | Неконечные даты | Обратный порядок | Пригодные интервалы |
|---|---:|---:|---:|---:|---:|
| Покупка → подтверждение | 96470 | 14 | 0 | 0 | 96456 |
| Подтверждение → перевозчик | 96470 | 15 | 0 | 1350 | 95105 |
| Перевозчик → вручение | 96470 | 1 | 0 | 23 | 96446 |

Для каждого этапа сумма четырёх групп равна 96 470. Исключения разных этапов могут пересекаться, поэтому их нельзя суммировать для получения числа исключённых заказов. Исходные даты не исправляются. Пригодность отдельного интервала не доказывает корректность всей цепочки дат.

Длительность этапа считается в сутках по 24 часа как разница временных меток в секундах, делённая на 86 400. Перцентили рассчитываются по пригодным интервалам этапа с округлением только при выводе. Медиана общего срока доставки рассчитывается по срокам отдельных заказов.

| Этап | Пригодные интервалы | Покрытие, % | Медиана, сутки | P90, сутки |
|---|---:|---:|---:|---:|
| Покупка → подтверждение | 96456 | 99.99 | 0.01 | 1.44 |
| Подтверждение → перевозчик | 95105 | 98.59 | 1.85 | 6.02 |
| Перевозчик → вручение | 96446 | 99.98 | 7.10 | 18.90 |

Суммы пригодных интервалов по двум группам совпали с общей проверкой каждого этапа. Наибольшая разница медиан наблюдается между передачей перевозчику и вручением и составляет 19.25 суток по опубликованным округлённым значениям. На этапе от подтверждения до передачи разница составляет 1.28 суток по медиане и 8.24 суток по P90. Сравнение описывает длительность этапов в двух группах. В наборе есть обещанная дата доставки заказа целиком. Для оценки просрочки конкретного этапа потребовались бы его плановые сроки.
