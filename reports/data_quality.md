## Связи

### Категории товаров

В справочнике переводов нет пустых английских названий. При этом у 610 товаров категория отсутствует. Ещё 13 товаров имеют заполненную категорию без соответствующего перевода:

| Исходная категория | Товаров |
|---|---:|
| portateis_cozinha_e_preparadores_de_alimentos | 10 |
| pc_gamer | 3 |

План обработки: raw оставить без изменений; отсутствующую категорию отображать как «Неизвестно», а для категории без перевода сохранять исходное название и отдельный признак отсутствия перевода. При соединении использовать подход, сохраняющий товары без совпадения в справочнике (LEFT JOIN). Ручные переводы пока не добавлялись. Количества относятся к товарам, не к заказам.

### Проверки наличия связанных записей

- Заказов без покупателя: 0.
- Позиций без соответствующего заказа: 0.
- Позиций без соответствующего продавца: 0 (результат пользователя в PostgreSQL).
- Позиций без соответствующего товара: 0 (результат пользователя в PostgreSQL).
- Заказов без позиций: 775, что совпадает с разностью 99 441 − 98 666.

| Статус заказа без позиций | Количество |
|---|---:|
| unavailable | 603 |
| canceled | 164 |
| created | 5 |
| invoiced | 2 |
| shipped | 1 |
| Итого | 775 |

Отсутствие позиций преимущественно связано со статусами unavailable и canceled. Распределение не доказывает причину отсутствия данных. Заказ shipped без позиций требует отдельного исследования. Среди заказов без позиций нет статуса delivered.

Все 775 заказов сохраняются в raw. В основную выборку доставки они не войдут по правилу статуса delivered; при построении витрин необходимо сохранить их для учёта исключений и месячной динамики. Не следует исключать их из общей таблицы заказов неявным INNER JOIN с позициями.

Заказ не включается в основную выборку доставленных заказов; фактическую просрочку по нему рассчитать нельзя без даты доставки. Эти сведения не доказывают потерю заказа или ответственность конкретного участника.
