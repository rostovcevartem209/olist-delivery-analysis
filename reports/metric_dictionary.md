# Определения метрик

Документ дополняется по мере реализации. Основной источник — mart.order_delivery, одна строка на заказ. Метки времени не получают назначенного часового пояса. Основные сроки рассчитываются по календарным датам.

## Выборка доставки

is_delivery_eligible требует статус delivered, заполненные конечные даты покупки, фактической и обещанной доставки, получение не раньше покупки по timestamp и обещанный день не раньше дня покупки. Причины исключения доступны в exclusion_reason. Промежуточные нарушения этапов помечаются отдельно has_stage_chronology_issue; сравнение общих KPI с исключением этой группы выполнено и приведено в delivery_overview.md; сравнение отдельных сегментов ещё предстоит.

## Показатели

| Поле или показатель | Определение | Выборка |
|---|---|---|
| Количество пригодных заказов | COUNT(*) при is_delivery_eligible | Пригодные заказы доставки |
| delivery_days | delivered_at::date − purchased_at::date | Пригодные заказы доставки |
| deviation_days | delivered_at::date − estimated_at::date; может быть отрицательным | Пригодные заказы доставки |
| delay_days | GREATEST(deviation_days, 0) | Пригодные заказы доставки |
| is_late | delivered_at::date > estimated_at::date | Пригодные заказы доставки |
| Доля просрочек, % | 100 × число is_late / количество пригодных заказов | Пригодные заказы доставки |
| Медиана времени доставки | PERCENTILE_CONT(0.5) по delivery_days | Все пригодные заказы доставки |
| P90 времени доставки | PERCENTILE_CONT(0.9) по delivery_days | Все пригодные заказы доставки |
| Медианная задержка | PERCENTILE_CONT(0.5) по delay_days | Только пригодные просроченные заказы |

У исключённых заказов delivery_days, deviation_days, delay_days, is_late и delay_group равны NULL. Нулевая задержка у пригодного заказа означает доставку вовремя или раньше. PERCENTILE_CONT допускает интерполяцию между наблюдениями; дробный результат сам по себе не является ошибкой. Доли сопровождаются абсолютными количествами, округление применяется при представлении.

## Группы задержки

Вовремя или раньше (deviation_days ≤ 0), 1–3 дня, 4–7 дней, 8–14 дней, 15 дней и более. Границы зафиксированы до сравнения оценок покупателей.

## Месячные показатели

mart.delivery_monthly содержит одну строку на календарный месяц покупки, включая месяцы без заказов между первой и последней покупкой. Подробности покрытия и рабочего окна сравнения — в monthly_coverage.md.

- total_orders — все заказы месяца покупки.
- eligible_orders — пригодные заказы доставки этого месяца.
- late_orders — просроченные среди пригодных; late_rate_pct = 100 × late_orders / eligible_orders.
- not_delivered_orders — все статусы, отличные от delivered.
- open_status_orders — created, approved, invoiced, processing, shipped; это зарегистрированные статусы исторического набора.
- canceled_or_unavailable_orders — canceled и unavailable.
- delivered_excluded — delivered, не прошедшие допуск по качеству.
- median_delivery_days и p90_delivery_days — по пригодным заказам соответствующего месяца.
- median_delay_late_days — только по просроченным пригодным заказам месяца.
- is_comparison_month — рабочее окно январь 2017 — июль 2018 при ненулевой пригодной выборке; comparison_note объясняет оговорки для остальных месяцев.

Отсутствующие количества отображаются как 0. При отсутствии пригодного знаменателя доля равна NULL; при отсутствии наблюдений для перцентиля он также NULL. Общую долю по нескольким месяцам нужно вычислять из суммы просроченных и суммы пригодных заказов; обычное среднее месячных процентов не является этой долей. Общие медианы и P90 рассчитываются по заказам, а не усреднением месячных перцентилей. Основные совокупные KPI включают все пригодные заказы; окно is_comparison_month используется отдельно для временного сравнения.
